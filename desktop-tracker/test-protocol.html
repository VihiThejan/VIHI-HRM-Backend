VIHI Time Tracker - Protocol Test

What this test does:

This page will try to launch the VIHI Time Tracker desktop app using the custom protocol handler (vihi-tracker://)

When you click the button below, your browser will ask you to confirm opening the application.

Step 1: Click the button below

Step 2: What should happen

  1. Browser shows a dialog: "Open debug_wrapper_new.bat?" or similar
  2. Click "Open debug_wrapper_new.bat" or "Always allow"
  3. A black command window (debug wrapper) should appear showing the arguments
  4. The Time Tracker desktop app window should appear
  5. It will show "Connection error" because we're using a fake token - that's OK!

Step 3: If nothing happens

Browser might be blocking the protocol handler.

Solutions:

  • Chrome: Go to chrome://settings/content/protocolHandlers and check if vihi-tracker is allowed
  • Edge: Go to edge://settings/content/protocolHandlers and check if vihi-tracker is allowed
  • Try clicking the button again - sometimes the first attempt is blocked

The Protocol URL Being Used:

vihi-tracker://start?token=TEST_TOKEN&name=Test%20User&ws_url=ws%3A%2F%2Flocalhost%3A5000&api_url=http%3A%2F%2Flocalhost%3A5000%2Fapi

Registry Key Check:

Run this in PowerShell to verify the protocol handler is registered:

Get-ItemProperty -Path "HKCU:\Software\Classes\vihi-tracker\shell\open\command" -Name "(default)"

Should output: D:\Projects\HRM\VIHI-HRM-Backend\desktop-tracker\debug_wrapper_new.bat "%1"
